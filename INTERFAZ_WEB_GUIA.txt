📁 MODO CON TUS DATOS
═══════════════════════════════════════════════════════════════════════════════

PASO 1: Selecciona "📁 Mis datos"
→ Aparecerá sección de upload de CSV

PASO 2: Obtén tu CSV de ESB Networks
→ Ve a https://www.esbnetworks.ie/
→ Login a tu cuenta
→ Descarga "Datos de consumo"
→ Formato: CSV con columnas:
   • MPRN, Meter Serial Number
   • Read Value (kWh)
   • Read Type (Normal/Estimated)
   • Read Date and End Time

PASO 3: Sube el archivo
→ Haz clic en "📤 Selecciona tu archivo CSV"
→ Elige el archivo descargado
→ Espera: "✓ Datos válidos"

PASO 4: Selecciona tarifas
→ Marca las que quieras comparar
→ Mínimo 1, máximo todas

PASO 5: Ajusta fechas si es necesario
→ Mes inicio: Cuando empieza tu período
→ Mes fin: Cuando termina

PASO 6: Ejecuta
→ Haz clic en "⚡ Ejecutar Simulación"
→ El motor procesa tu CSV + tarifas
→ Calcula costos reales
→ Genera ranking personalizado

🐛 SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: Interfaz no carga
SOLUCIÓN:
1. Comprueba que el servidor está corriendo
   → Terminal debería mostrar "Running on http://127.0.0.1:5000"
2. Abre en navegador: http://localhost:5000 (no https)
3. Limpia caché: Ctrl+Shift+Delete
4. Intenta incógnito: Ctrl+Shift+N

PROBLEMA: "Cannot POST /api/demo-simulate"
SOLUCIÓN:
1. Reinicia el servidor: Ctrl+C y vuelve a ejecutar
2. Comprueba que Flask está activo en terminal
3. Abre consola del navegador (F12 → Console)
4. Mira qué error reporta exactamente

PROBLEMA: CSV no se procesa
SOLUCIÓN:
1. Verifica que sea formato CSV (no Excel)
2. Columnas deben ser exactamente:
   ✓ MPRN, Meter Serial Number
   ✓ Read Value
   ✓ Read Type
   ✓ Read Date and End Time
3. Dates en formato: dd-mm-yyyy hh:mm
4. Tamaño < 16 MB

PROBLEMA: Puerto 5000 ocupado
SOLUCIÓN:
$ lsof -i :5000          # Ver qué ocupa el puerto
$ kill -9 <PID>         # Matar ese proceso
O usar otro puerto:
$ export FLASK_PORT=5001 && python3 app.py
Luego: http://localhost:5001

ARQUITECTURA:
┌─────────────────────────────────────────────────────────────┐
│ FRONTEND (Navegador)                                        │
│ • HTML5 + CSS3 (sin frameworks)                              │
│ • Vanilla JavaScript (sin jQuery, React, Vue)                │
│ • Fetch API para comunicación con backend                    │
│ • Responsive design (funciona en móvil, tablet, desktop)     │
│                                                             │
│ ↕ COMUNICACIÓN (HTTP/JSON)                                  │
│                                                             │
│ BACKEND (Flask)                                             │
│ • Python 3.8+                                               │
│ • Flask web framework                                       │
│ • CORS habilitado (cross-origin requests)                    │
│ • Endpoints REST:                                           │
│   GET  /api/health          Health check                     │
│   GET  /api/tariffs         Obtener tarifas                  │
│   POST /api/upload-csv      Procesar CSV                     │
│   POST /api/simulate        Simulación con datos             │
│   POST /api/demo-simulate   Simulación con demo              │
│                                                             │
│ MOTOR DE SIMULACIÓN                                         │
│ • src/simulation_engine.py  Cálculos (validado)              │
│ • src/consumption_processor.py Limpieza de datos             │
│ • agents/advisor.py         Análisis y ranking               │
└─────────────────────────────────────────────────────────────┘

FLUJO DE DATOS:
Usuario hace clic en "Simular"
  ↓
JavaScript envía JSON al backend
  ↓
Flask recibe en /api/demo-simulate
  ↓
Python crea perfiles de consumo
  ↓
Motor de simulación calcula costos
  ↓
Asesor genera ranking
  ↓
Backend devuelve JSON con resultados
  ↓
JavaScript renderiza en HTML
  ↓
Usuario ve ranking en pantalla
