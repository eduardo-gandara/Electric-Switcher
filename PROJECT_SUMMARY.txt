═══════════════════════════════════════════════════════════════════════════════
🔑 CARACTERÍSTICAS PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

Motor de Simulación:
  ✓ Determinista (código puro, no ML)
  ✓ Validado contra facturas reales
  ✓ Reproduce fórmula de Bord Gáis exactamente
  ✓ Maneja 3 franjas: día, noche, pico
  ✓ Incluye descuentos, cargos, IVA, PSO levy

Procesamiento de Consumo:
  ✓ Limpia datos de ESB Networks
  ✓ Elimina duplicados exactos
  ✓ Imputa huecos (~0.2% del período)
  ✓ Ajusta cambios de hora (DST)
  ✓ Construye perfil agregado por franja

Asesor:
  ✓ Ranking de tarifas por costo neto
  ✓ Análisis de sensibilidad (+/-20% consumo)
  ✓ Identificación de riesgos
  ✓ Validaciones de esquema y rango
  ✓ Recomendaciones personalizadas

Pipeline:
  ✓ Orquestación automática
  ✓ CLI fácil de usar
  ✓ Exportación en JSON
  ✓ Modo demo sin datos reales
  ✓ Modo producción con CSV real

💡 APRENDIZAJES Y DECISIONES

   • Tests contra 4 facturas reales

   Resultado: Fácil de extender (Fases 2-5)
