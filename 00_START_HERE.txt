🔧 CÓMO EJECUTAR
═══════════════════════════════════════════════════════════════════════════════

INSTALACIÓN (primero una sola vez):

  pip install -r requirements.txt
  source venv/bin/activate

DEMOSTRACIÓN (sin datos reales):

  $ python3 demo.py
  
  Esto:
  • Crea perfiles de consumo de ejemplo
  • Carga 2 tarifas de ejemplo
  • Ejecuta simulación
  • Genera ranking y análisis
  • Valida contra facturas reales

PRUEBAS DE VALIDACIÓN:

  $ python3 test_simulation.py
  
  Esto:
  • Calcula costo de 4 meses reales
  • Compara con facturas verdaderas
  • Muestra errores (deberían estar <2%)

CON DATOS REALES (cuando tengas CSV):

  $ python3 src/main.py \
      --csv datos/consumo_esb.csv \
      --tariffs config/tarifas.json

  Opciones:
  --csv RUTA           Ruta del CSV de ESB Networks
  --tariffs RUTA       Ruta del JSON de tarifas
  --demo               Modo demostración

🎓 APRENDIZAJE: AI AGENTS
═══════════════════════════════════════════════════════════════════════════════

Este proyecto demuestra un workflow completo de punta a punta:

1. ENTRADA (Agents):
   • Agente recopilador: Extrae tarifas de webs
   • Agente procesador: Limpia datos de consumo

2. NÚCLEO (Motor):
   • Simulación determinista: Calcula costos
   • Validación: Compara contra realidad

3. SALIDA (Agents):
   • Asesor: Genera ranking y análisis
   • Recomendaciones: Ayuda a decidir

4. PRESENTACIÓN:
   • CLI, JSON, gráficos
   • Para humanos y máquinas
